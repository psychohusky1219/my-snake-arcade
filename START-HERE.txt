PLAY IN YOUR BROWSER NOW:
https://my-snake-arcade.vercel.app/

The web game is already published. The ZIP is not needed just to play.

START THE NATIVE IPHONE BUILD FROM WINDOWS:
1. Right-click this ZIP and choose Extract All. Open the extracted folder.
2. Review README.md and double-click Publish-GitHub.cmd.
3. Confirm PUBLIC source publishing. The script offers to install Git/GitHub CLI
   only if missing, and opens GitHub's official browser sign-in.
4. Confirm your GitHub account. It creates a NEW my-snake-arcade repository and
   pushes the included files. It never overwrites an existing repository.
5. The Actions page opens. After the build succeeds, use the repository's
   Releases page to download MySnake-unsigned.ipa and INSTALL-WINDOWS.md.

The GitHub repository and cloud build have NOT been created or run by this ZIP.
They are created only when you approve and run the Windows publisher.
No Apple passwords, signing certificates, or paid accounts are needed for the build.
Native installation still requires signing the IPA for your iPhone.
